# Birthday Tribute — Hon. Daud Olasupo Olukosi I

Responsive birthday tribute in ash, cream, and muted gold, built with plain HTML, CSS, and JavaScript.

## Publish with GitHub Pages
1. Open **Settings → Pages**.
2. Under Build and deployment, choose **Deploy from a branch**.
3. Select `main` and `/(root)`, then Save.

The portrait should be placed at `assets/hon-daud-portrait.jpg`. The supplied screenshot was cropped to create this portrait; upload the image file there to show it on the page.
